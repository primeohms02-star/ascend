# ASCEND Work — Pilot Specification

## Product promise

ASCEND Work connects direction to paid, verifiable experience. Its core unit is a **Paid Mission**: a fixed-scope remote project from a verified organisation, matched to a student's direction and demonstrated skills.

Paid Missions are not ordinary Atlas Missions and are not external opportunity listings. They have an employer, disclosed payment, deliverables, selection, submission, review and a permanent audit trail.

## Commercial access

- Individual ASCEND subscription: **₦3,500 per month**.
- Sponsored access: a university, company, foundation or public programme funds an approved cohort.
- Pilot access: ASCEND manually grants access during controlled validation.
- Students keep the full advertised project payment. ASCEND's project service fee is charged to the employer.
- Access never guarantees selection, work or income.

The pilot records entitlements but does not process subscriptions or project payments. Payment automation is a later phase after provider, dispute, tax and marketplace requirements are verified.

## Pilot lifecycle

1. ASCEND verifies an organisation.
2. An admin reviews scope, hours, payment, deliverables and deadlines.
3. ASCEND publishes the Paid Mission.
4. Eligible users with active ASCEND Work access apply once.
5. The employer/admin shortlists and accepts a student.
6. The student submits deliverables through an auditable project record.
7. The employer approves, requests a revision or opens a dispute.
8. Approved work becomes verified evidence on the student's ASCEND profile.

## Safety rules

- No project is public before organisation and project verification.
- No academic cheating, illegal work, deceptive reviews, speculative unpaid work or recruitment fees.
- Every project must show currency, payment, estimated hours, deadline, deliverables and required skills.
- Applications are idempotent: one application per student per project.
- Private Atlas conversations and reflections are never exposed to employers or institutions.
- Institutions receive only appropriate aggregate programme outcomes.
- Student work remains exportable; retention must come from continuing value, not hostage data.

## Pilot scope

The first release includes the database foundation, access grants, verified organisations, published projects, student discovery, project details, applications and admin-only creation APIs. Employer self-service, automated payouts, messaging, deliverable uploads, reviews, disputes, portfolio publication and institutional dashboards follow after the controlled pilot proves supply and completion quality.
